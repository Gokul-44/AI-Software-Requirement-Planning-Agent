# Work split

All four members (Gokul Faleja, Saransh Sarang Naik, Akshay Kumar Tapraniya and Shreya Tiwari) worked together on
every part of the project. There were no individual technical roles: each of us took part in the planning, the design,
the code, the testing, the deployment and the documentation, and each of us can explain all 8 stages.

## Main work areas

| Work area                                                                  | Who         |
| -------------------------------------------------------------------------- | ----------- |
| Problem analysis and review of the original project decks                  | All members |
| Design document, algorithms and locked decisions                           | All members |
| Data contracts and schemas (`packages/shared`)                             | All members |
| Scheduling algorithms: Kahn, Tarjan, CPM, priority order, sprint packing, signals (`packages/scheduler`) | All members |
| Prompts, model harness, Gemini, mock and replay providers (`apps/api`)     | All members |
| API, pipeline orchestration, database and migrations                       | All members |
| Website: pages, plan tabs, graph, Gantt, what-if panel (`apps/web`)        | All members |
| Exporters: Jira CSV and Markdown (`packages/exporters`)                    | All members |
| Testing: unit, contract, property-based and end-to-end tests               | All members |
| Evaluation runs, results and the human rubric                              | All members |
| Deployment: Vercel, Render, Neon, GitHub Actions                           | All members |
| Documentation, report, presentation and demo preparation                   | All members |
